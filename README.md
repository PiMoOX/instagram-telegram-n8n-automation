# instagram-telegram-n8n-automation
An n8n automation workflow for connecting Instagram Direct messages with Telegram, enabling sales teams to receive customer messages and send replies back to Instagram.

README introduction
Instagram ↔ Telegram n8n Automation

An automation workflow built with n8n to connect Instagram Direct messages with Telegram.

The workflow allows sales teams to receive Instagram customer messages directly in Telegram and send their replies back to Instagram through an automated workflow.

#Features
Instagram Direct → Telegram
Telegram → Instagram replies
Customer identification
Support for text messages
Support for voice messages
Automated message routing
n8n-based workflow automation
Technologies
n8n
Instagram Graph API
Telegram Bot API
Webhooks
Workflow

Instagram → n8n → Telegram → Sales Expert → n8n → Instagram

Note

This repository contains the workflow configuration and documentation. Sensitive credentials and API tokens are not included.
